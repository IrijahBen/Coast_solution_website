# Coast Solutions

**Unified applications built for modern enterprise scale.**

---

## Overview

Coast Solutions is a comprehensive ecosystem of specialized enterprise tools designed to connect sales, inventory, education, career growth, and commerce into a single, unified workspace.

---

## The Coast Ecosystem Suite

1. **Coast BMS (Business Management Suite)** — Operating system for multi-branch retail and distribution with lightning-fast POS terminals, offline sync protection, and centralized inventory tracking.
2. **Coast LMS (Learning Management System)** — Structured training and onboarding modules with drag-and-drop course builders and automated certifications.
3. **Coast Forms (Advanced Data Collection)** — Custom surveys and intake workflows featuring conditional logic branching and submission dashboards.
4. **Coast CV Builder (Professional Career Suite)** — Recruiter-approved, ATS-optimized resume creation and career profile management.
5. **Coast Open Market (B2B Digital Marketplace)** — Secure marketplace connecting verified manufacturers and distributors through milestone escrow commerce.

---

## Tech Stack

* **Framework:** [Next.js](https://nextjs.org) (App Router)
* **Library:** [React](https://react.dev)
* **Styling:** [Tailwind CSS](https://tailwindcss.com)
* **Data Storage:** LocalStorage & Next.js API Routes (for admin CMS and inquiry logging)

---

## Core Features

* **Executive Admin Control Center:** Secure passcode-authenticated studio for publishing blog articles, managing custom categories, authorizing writers, and reviewing live demo/waitlist requests.
* **Dual-Mode Request Modals:** Dynamic modal interface that differentiates between Live Demo requests (with automated test credentials routing) and Priority Waitlist signups.
* **Platform Interface Showcase:** Interactive browser mockup frame displaying real-world application dashboard views.
* **Responsive Marketing Layout:** Fully adaptive mobile navigation drawer and custom branded header (`coast.png`).

## Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) 18+
* [pnpm](https://pnpm.io/) (recommended)

### 1. Clone and Install

```bash
git clone https://github.com/IrijahBen/Coast_solution_website.git
cd Coast_solution_website
pnpm install

```

### 2. Run Development Server

```bash
pnpm dev

```

Open [http://localhost:3000](http://localhost:3000) to view the live platform.

### 3. Build for Production

```bash
pnpm build
pnpm start

```
